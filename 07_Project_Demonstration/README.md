# Phase 7: Project Demonstration

## 1. Introduction

This phase presents the working demonstration of the Metro Ticket Booking Application developed using ServiceNow.

## 2. Demonstration Objectives

The demonstration showcases the main application features and verifies the booking experience through the Service Portal.

## 3. Features Demonstrated

The demo video covers:

1. Metro Station Details table and station records.
2. Book A Metro Ticket catalog item.
3. Booking form and catalog variables.
4. Mandatory-field validation.
5. Conditional payment-field behaviour when "Others" is selected.
6. QR-code generation and display.
7. Flow Designer configuration.
