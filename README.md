# Metro Ticket Booking Application

## Project Overview

The Metro Ticket Booking Application is a ServiceNow-based digital metro ticketing system designed to simplify the process of booking metro tickets through the Service Portal.

The application allows users to select their starting station, destination station, journey type, number of passengers, and payment mode. The system supports fare calculation, ticket processing, and QR-based digital ticket generation.

## Objectives

- Provide a simple digital metro ticket booking process.
- Allow users to select metro stations easily.
- Support single and return journeys.
- Allow users to select the number of passengers.
- Calculate the applicable ticket fare.
- Provide different payment options.
- Generate a QR-based digital ticket.
- Store ticket information in ServiceNow.
- Automate ticket processing using ServiceNow workflows.

## Key Features

- Metro station selection
- Single and return journey options
- Passenger selection
- Fare calculation
- Payment mode selection
- Conditional payment-mode field
- QR code ticket generation
- Service Portal integration
- Flow Designer automation
- Ticket data storage
