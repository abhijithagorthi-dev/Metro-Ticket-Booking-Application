# Phase 1: Ideation

## Project Title
Metro Ticket Booking Application using ServiceNow

## Problem Statement
Traditional ticket booking processes can involve manual steps and inconvenience for passengers. A digital ticket booking application can simplify the collection of journey details and provide a QR-based ticket display.

## Proposed Solution
The project implements a Metro Ticket Booking Application using ServiceNow. Users can select their source and destination stations, choose their journey type and passenger count, enter payment details, and view a QR code through the booking interface.

## Objectives
- Create a digital metro ticket booking form.
- Configure metro station selection.
- Capture journey, passenger and payment details.
- Implement conditional payment-field behaviour.
- Generate and display a QR code.
- Test the booking experience through the Service Portal.

## Expected Outcome
A working ServiceNow prototype demonstrating the metro ticket booking form, conditional UI behaviour, QR-code display and configured workflow automation.
