# Project Overview

## Project Name

Metro Ticket Booking Application

## Introduction

The Metro Ticket Booking Application is developed using ServiceNow to provide a digital and user-friendly solution for metro ticket booking.

The application allows commuters to select their starting station, destination station, journey type, number of passengers, and payment mode. The system processes the ticket request and provides a digital QR-based ticket.

## Problem Statement

Traditional metro ticket booking can involve manual processes and may require users to wait for ticket generation. There is a need for a simple digital system that can automate ticket booking, fare processing, and ticket generation.

## Proposed Solution

The proposed solution uses ServiceNow Service Catalog and Service Portal to provide an online metro ticket booking experience.

The user can:

1. Open the Metro Ticket Booking service.
2. Select the starting station.
3. Select the destination station.
4. Select the journey type.
5. Select the number of passengers.
6. View/enter the applicable fare.
7. Select a payment mode.
8. Generate a QR-based digital ticket.
9. Submit the ticket request.

## Objectives

- Digitize the metro ticket booking process.
- Provide an easy-to-use Service Portal interface.
- Store metro station and ticket information in ServiceNow.
- Automate ticket processing.
- Support different journey types and passenger counts.
- Provide QR-based digital ticket generation.
- Improve the overall user experience.

## ServiceNow Components Used

- Service Catalog
- Service Portal
- Catalog Items
- Catalog Variables
- Catalog UI Policies
- Catalog Client Scripts
- Custom Tables
- Flow Designer
- ServiceNow scripting

## Project Outcome

The application provides an end-to-end digital metro ticket booking workflow through ServiceNow, from user ticket submission to ticket processing and QR-based ticket generation.
